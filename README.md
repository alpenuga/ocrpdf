# ocrpdf
Преобразователь документов 
=====================================

OCR книг картинок с текстом 
=====================================

Первый запуск только с интернетом (скачиваются Tesseract, PDF.js и языковые модели).
Потом UI и уже скачанные языки работают офлайн. PDF/картинки всегда выбираете с устройства.

 ЯЗЫКИ
--------
Русский
  Художественный текст, обычные учебники на русском.

English
  Только латиница.

Русский + English
  Смешанные страницы, термины, задания с EN-формулировками.

Узбекский (латиница)
  o‘ g‘ sh ch. Первая загрузка качает uzb.traineddata.

Узбекский (кириллица)
  ў қ ғ ҳ. Качает uzb_cyrl.traineddata.

Русский + узбекский (кириллица)
  Типичные школьные книги РУз на кириллице.

Русский + узбекский (латиница)
  Смесь русского и узбекской латиницы.

Узбекский + English
  Латиница / кириллица + английские термины (два отдельных пункта).

Русский + узб. кир. + English
  Три языка. Медленнее и «шумнее», только если страница реально смешанная.

Наука: рус + eng + греческий
  Физика/математика: α β λ π Δ Σ. Первый раз качает ell.traineddata.

Наука: рус + узб. кир. + eng + греч.
  То же плюс узбекская кириллица. Самый тяжёлый набор.

 ОГРАНИЧЕНИЯ
--------------
Нет понимания смысла формул, нет LaTeX.
Нет сервера: всё в браузере, память конечна.
Первый раз каждый новый язык качает модель.
