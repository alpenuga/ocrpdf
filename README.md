# ocrpdf
Преобразователь документов 

OCR книг и PDF — инструкция по режимам
=====================================

Первый запуск только с интернетом (скачиваются Tesseract, PDF.js и языковые модели).
Потом UI и уже скачанные языки работают офлайн. PDF/картинки всегда выбираете с устройства.


1. ЯЗЫКИ
--------
Русский
  Художественный текст, обычные учебники на русском.

English
  Только латиница.

Русский + English
  Смешанные страницы, термины, задания с EN-формулировками.

Узбекский (латиница)
  o‘ g‘ sh ch. Первая загрузка качает uzb.traineddata.

Узбекский (кириллица)
  ў қ ғ ҳ. Качает uzb_cyrl.traineddata.

Русский + узбекский (кириллица)
  Типичные школьные книги РУз на кириллице.

Русский + узбекский (латиница)
  Смесь русского и узбекской латиницы.

Узбекский + English
  Латиница / кириллица + английские термины (два отдельных пункта).

Русский + узб. кир. + English
  Три языка. Медленнее и «шумнее», только если страница реально смешанная.

Наука: рус + eng + греческий
  Физика/математика: α β λ π Δ Σ. Первый раз качает ell.traineddata.

Наука: рус + узб. кир. + eng + греч.
  То же плюс узбекская кириллица. Самый тяжёлый набор.


2. МАСШТАБ (рендер PDF)
-----------------------
1.5  Быстрее, меньше память. Черновик, телефон, много страниц.
2    Баланс. Обычный текст и простые таблицы.
2.5  Учебники, мелкий шрифт, формулы, сетки таблиц. Медленнее, больше RAM.


3. СЕГМЕНТАЦИЯ (PSM Tesseract)
------------------------------
Авто
  Разные блоки на странице. Если «единый блок» склеивает колонки.

Авто + OSD
  Плюс определение поворота. Кривые сканы.

Одна колонка
  Учебник в одну колонку, таблицы с линейками. Часто лучший выбор для алгебры.

Единый блок  (по умолчанию)
  Сплошной текст без колонок.

Разреженный текст
  Подписи к рисункам, редкие формулы на белом поле. Не для сплошных абзацев.


4. ПРЕДОБРАБОТКА
----------------
Вкл: серый + контраст, обычные книги читаются лучше.
Научный режим сам снижает контраст (чтобы не съесть тонкие минусы и линии сетки).
Выкл: цветные схемы, очень бледный или уже бинаризованный скан.


5. НАУКА: ТАБЛИЦЫ, СТЕПЕНИ, ХИМИЯ
---------------------------------
Вкл (рекомендуется для алгебры, физики, химии):
  - ищет линейки таблицы и OCR каждой ячейки;
  - если линеек нет — пробует собрать колонки по выравниванию;
  - вставляет Markdown-таблицу в текст;
  - x2 → x², H2O → H₂O, стрелки реакций;
  - мелкие цифры выше/ниже строки → надстрочные/подстрочные;
  - формулы не склеиваются с абзацами.

Выкл: только обычный текст + склейка переносов (художка, история).

Ожидания:
  Таблица с нарисованными линиями — заметно лучше.
  «Слепая» таблица без линий — иногда колонки, иногда нет.
  x², v₀, простые равенства — часто чинятся.
  Дробь столбиком, интеграл с пределами, система уравнений — нет (нужен LaTeX-OCR, не в браузере на Pages).


6. ПРЕВЬЮ СТРАНИЦЫ
------------------
После OCR справа скан текущей страницы.

Голубая рамка  — найденная таблица.
Жёлтая рамка   — строка похожа на формулу, проверьте глазами.
Розовая рамка  — низкая уверенность OCR + цифры/символы.

В списке страниц: «табл.» и число предупреждений.
Клик по рамке или пункту списка выделяет фрагмент в текстовом поле — правьте там.

Кнопка «Весь текст» — все страницы в одном поле, превью остаётся на выбранной странице.


7. ЭКСПОРТ
----------
TXT              Сплошной текст после ваших правок.
Markdown         Заголовки страниц + таблицы | col | col |.
JSON             Текст, таблица-матрица, flags (рамки), слова с координатами.
PDF с картинками Страницы как JPEG (для сдачи скана).
Searchable PDF   Картинка + невидимый слой слов (поиск в Acrobat/браузере).
PDF с текстом    Только набор, без картинок; кириллица в jsPDF может выглядеть бедно — для правок лучше TXT/MD.


8. ТИПОВЫЕ СЦЕНАРИИ
-------------------
Обычная книга на русском
  Язык: Русский. Наука: выкл. Масштаб 2. Сегментация: единый блок.

Алгебра / физика, таблицы с линейками
  Язык: Наука рус+eng+греч. Наука: вкл. Масштаб 2.5. Сегментация: одна колонка.
  Смотрите голубые рамки, жёлтые формулы, правьте в поле.

Химия, формулы веществ
  Тот же научный язык. Наука: вкл. Проверьте H₂O / индексы на превью.

Узбекский учебник кириллицей
  Русский + узбекский (кириллица). Наука по содержанию.

Смешанный рус/узб + задачи по физике
  Наука: рус + узб. кир. + eng + греч. Масштаб 2.5. Частями, не всю книгу сразу.

Толстый PDF
  Режьте по главам. На телефоне масштаб 1.5. Кнопка «Отмена» сохраняет уже готовые страницы в сессии (до перезагрузки).
